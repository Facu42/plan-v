# 02 — Navegación de acciones rápidas de paciente

## Objetivo

Convertir las acciones visibles de la portada paciente en navegación funcional: el acceso a menú abre “Mi plan” y responder a Verónica abre “Mensajes”.

## Aceptación

- [x] “Ver menú” abre la pestaña “Mi plan”.
- [x] El botón para responder a Verónica abre “Mensajes”.
- [x] La verificación de navegador confirma ambas rutas en modo demo.
- [x] `npm run check` y `npm run build` pasan.
