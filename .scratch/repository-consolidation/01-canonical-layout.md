# 01 — Consolidar workspace

## Objetivo

Usar `plan-v/` como único árbol activo y conservar el prototipo anterior como referencia no ejecutable.

## Aceptación

- [x] El código activo y su repositorio Git quedan en `plan-v/`.
- [x] El prototipo previo se preserva bajo `../archive/legacy-prototype-2026-09-04/`.
- [x] La raíz del workspace documenta el punto de entrada vigente.
- [x] La documentación del repo activo explica las reglas de reutilización.
